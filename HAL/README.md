

# Understanding `main.h`

The `main.h` file is located at:

```
Core/Inc/main.h
```

This file is automatically generated by STM32CubeMX/STM32CubeIDE. It contains the definitions (macros) for GPIO pins and ports used in your project.

Example:

```c
#define LED2_Pin GPIO_PIN_5
#define LED2_GPIO_Port GPIOA

#define B1_Pin GPIO_PIN_13
#define B1_GPIO_Port GPIOC
```

Instead of writing:

```c
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
```

you can write:

```c
HAL_GPIO_WritePin(LED2_GPIO_Port, LED2_Pin, GPIO_PIN_SET);
```

Using these macros makes the code easier to read and maintain.

---

# Useful Definitions Found in Header Files

When writing HAL code, many useful definitions are already available after including:

```c
#include "main.h"
```

or

```c
#include "stm32f4xx_hal.h"     // Depends on your STM32 family
```

Some commonly used definitions are:

## GPIO Ports

```c
GPIOA
GPIOB
GPIOC
GPIOD
GPIOE
```

These represent the GPIO port addresses.

---

## GPIO Pin Numbers

```c
GPIO_PIN_0
GPIO_PIN_1
GPIO_PIN_2
...
GPIO_PIN_15
```

These macros represent the 16 GPIO pins available on each port.

Example:

```c
GPIOA + GPIO_PIN_5
```

means **PA5**.

---

## GPIO Pin States

```c
GPIO_PIN_SET
GPIO_PIN_RESET
```

Used for writing HIGH or LOW to a pin.

Example:

```c
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
```

---

## GPIO Modes

These are used while configuring a GPIO.

```c
GPIO_MODE_INPUT
GPIO_MODE_OUTPUT_PP
GPIO_MODE_OUTPUT_OD
GPIO_MODE_AF_PP
GPIO_MODE_ANALOG
GPIO_MODE_IT_RISING
GPIO_MODE_IT_FALLING
GPIO_MODE_IT_RISING_FALLING
```

---

## GPIO Pull Configuration

```c
GPIO_NOPULL
GPIO_PULLUP
GPIO_PULLDOWN
```

---

## GPIO Speed

```c
GPIO_SPEED_FREQ_LOW
GPIO_SPEED_FREQ_MEDIUM
GPIO_SPEED_FREQ_HIGH
GPIO_SPEED_FREQ_VERY_HIGH
```

# Common HAL GPIO Function Prototypes

If you open:

```
Drivers/STM32xxxx_HAL_Driver/Inc/stm32xxxx_hal_gpio.h
```

you can find the function declarations (prototypes) used for GPIO operations.

Examples:

```c
HAL_GPIO_WritePin();

HAL_GPIO_ReadPin();

HAL_GPIO_TogglePin();

HAL_GPIO_Init();

HAL_GPIO_DeInit();

HAL_GPIO_LockPin();

HAL_GPIO_EXTI_IRQHandler();

HAL_GPIO_EXTI_Callback();
```

These are only the function declarations. Their actual implementation is available in:

```
stm32xxxx_hal_gpio.c
```

---

# Tip

Whenever you forget the arguments of a HAL function, simply type:

```c
HAL_GPIO_
```

and press **Ctrl + Space** (or let IntelliSense autocomplete). STM32CubeIDE/VS Code will show all available HAL GPIO functions along with their parameters.

Similarly, typing:

```c
GPIO_
```

will display available GPIO macros such as:

```c
GPIO_PIN_x
GPIO_MODE_x
GPIO_PULL_x
GPIO_SPEED_FREQ_x
GPIO_PIN_SET
GPIO_PIN_RESET
```

This is one of the easiest ways to explore the HAL library while coding.
