# 🤖 Automated Rubik's Cube Solver — STM32

An embedded systems project using an **STM32 Nucleo-F446RE** to control six stepper motors for an automated Rubik's Cube.

## Features
- Automatic cube scrambling using programmed motor movements.
- Accepts solving moves generated by an online Rubik's Cube solver website.
- UART TX/RX communication with interrupt-based reception.
- GPIO-based STEP/DIR control for six stepper motors.
- Executes the received moves to rotate the cube toward its solved state.

## Hardware & Tools
- **MCU:** STM32 Nucleo-F446RE
- **Motor Driver:** TMC2208
- **Motors:** 6 stepper motors
- **IDE:** STM32CubeIDE
- **Communication:** UART at 115200 baud
- **Serial Terminal:** Tera Term
- **Firmware:** STM32 HAL

## Motor Mapping

| Motor | Cube Face |
|---|---|
| M1 | U — Up |
| M2 | R — Right |
| M3 | F — Front |
| M4 | D — Down |
| M5 | L — Left |
| M6 | B — Back |

## Working Principle
1. The motors scramble the cube using programmed movements.
2. Enter the scrambled cube state into an online Rubik's Cube solver website.
3. Obtain the solution moves and send them to the STM32 through UART.
4. The STM32 interprets the moves and controls the corresponding motors to solve the cube.

## Concepts Used
GPIO • UART TX/RX • Interrupts • STEP/DIR Control • Timing Delays • STM32 HAL
